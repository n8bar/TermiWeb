# 0.1.2 Release Publication Draft

## Purpose

Record the `0.1.2` GitHub release body and publication procedure for M10. Published on 2026-09-11 as [v0.1.2](https://github.com/n8bar/TermiWeb/releases/tag/v0.1.2); both downloads and the public release surfaces were verified.

## GitHub Release Body Draft

```md
## What changed

- **Installer:** handles password setup, optional auto-start, firewall access on all network profiles, shortcuts, and uninstall. Config and workspace state live in `%ProgramData%\TermiWeb`.
- **Auto-start:** works before sign-in without a Windows password, including Hello/PIN-only accounts, in both packages. Shells run as `SYSTEM` until TermiWeb is stopped and started manually.
- **Starting folder:** `TERMIWEB_START_DIRECTORY` sets where new shells open; the installer defaults it to your user folder.
- **Instance titles:** show shell-provided names with stable numbered fallbacks and scrolling long titles on phones. Fixed executable paths appearing as names under Windows PowerShell.
- **Terminal bell:** adds visual alerts; optional sound and phone vibration are off by default.
- **Fixes:** mobile Select mode stays open through keyboard changes; portable launchers no longer leave blank console windows.

## Install

1. Download and run `TermiWeb-0.1.2-windows-x64-setup.exe` from Assets below (recommended).
2. For the unsigned installer's SmartScreen prompt, choose **More info → Run anyway**, then approve elevation.
3. Complete setup and launch TermiWeb at http://127.0.0.1:22443.

**Portable:** unpack `TermiWeb-0.1.2-windows-x64.zip`, read `1.Start-Here.md`, and run `Set Up TermiWeb.cmd`. State stays in that folder. See the [README](https://github.com/n8bar/TermiWeb/blob/main/README.md) for zip-to-installer migration.

## Before you use it

Windows only; all shells are elevated. Intended for trusted private networks, with single-user authentication and no TLS. Securing internet exposure is your responsibility. Read the [disclaimer](https://github.com/n8bar/TermiWeb/blob/main/DISCLAIMER.md).

Verified both packages on clean Windows 11 with Hello-only sign-in: setup, upgrade, before-sign-in LAN access, uninstall/reinstall with retained or removed config, and portable launch controls. Previous mobile fixes were rechecked on hardware.
```

## Manual Publication Order

1. Confirm `main` contains the final M10 release surface, including the SmartScreen screenshot captured during the VM run and now shown on the site and in the README.
2. Run `npm run typecheck`, `npm test`, `npm run build`, `npm run build:site`, and `npm run package:release`.
3. Verify the local outputs: `artifacts/release/TermiWeb-0.1.2-windows-x64-setup.exe`, `artifacts/release/TermiWeb-0.1.2-windows-x64.zip`, and `dist/site/`.
4. Draft the GitHub release titled `TermiWeb 0.1.2`, upload the installer as the first asset and the zip as the second.
5. Push the final release-surface updates to `main`.
6. Push `main` and let the GitHub Pages workflow deploy the site.
7. Publish the GitHub release.
8. Verify the live README, release, website, download redirect, SmartScreen guidance, and both artifacts together.

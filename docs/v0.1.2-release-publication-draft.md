# 0.1.2 Release Publication Draft

## Purpose

Hold the current internal draft for the `0.1.2` GitHub release body and the manual publication order for the M10 patch release.

## GitHub Release Body Draft

```md
TermiWeb 0.1.2 replaces the zip-and-scripts setup with a Windows installer, and adds instance titles and a terminal bell.

The installer is the primary download from here on. The portable zip stays available as a secondary download.

## What changed

- **A real installer.** Installs to Program Files, collects the app password, offers before-sign-in auto-start, opens the firewall on every network profile, and registers a normal uninstall entry. Config and state live under `%ProgramData%\TermiWeb`.
- **No Windows account password, ever.** Auto-start runs as `SYSTEM` with no stored credentials, so Hello-only and PIN-only machines work. The zip gets this too. Shells on an auto-started server stay `SYSTEM` until you stop and start it yourself.
- **`TERMIWEB_START_DIRECTORY`** chooses where new shells open. The installer points it at your profile.
- **Instance titles.** An instance shows the title its shell sets, otherwise a stable number that never renumbers. Long titles ellipsize on desktop and scroll on phones.
- **Terminal bell.** The ringing instance flashes and keeps a badge until you touch it, the browser tab shows a marker, and an off-by-default Sound toggle plays a tone and vibrates on phones.
- **Fixes.** Mobile Select mode no longer closes itself when the keyboard appears. The zip's launchers no longer leave an empty console on screen. Instances no longer show a truncated shell path as their name.

## Install

1. Download `TermiWeb-0.1.2-windows-x64-setup.exe`.
2. Run it. It is unsigned, so SmartScreen says "Windows protected your PC": choose `More info`, then `Run anyway`.
3. Set the TermiWeb password and decide whether it starts before sign-in.
4. Let the finish page start it and open `http://127.0.0.1:22443`.

Portable zip: `TermiWeb-0.1.2-windows-x64.zip` keeps config and state in its own folder. Unpack it, read `1.Start-Here.md`, run `Set Up TermiWeb.cmd`. Moving from the zip to the installer is described in the README.

## Verification

Both downloads ran end to end on a clean Windows 11 machine with Microsoft-account, Hello-only sign-in: install, upgrade over itself, reboot with nobody signed in and a phone attaching over the LAN, both uninstall paths, and the zip's own setup and auto-start.

## Operating boundaries

- Windows hosts only
- Every shell in `0.1` is elevated
- Built for a trusted private network
- WAN exposure is possible, but securing it is up to you
- Single-user auth without TLS
```

# 0.1.2 Release Publication Draft

## Purpose

Hold the current internal draft for the `0.1.2` GitHub release body and the manual publication order for the M10 patch release.

## GitHub Release Body Draft

```md
TermiWeb 0.1.2 replaces the zip-and-scripts setup with a Windows installer, fixes the mobile Select-mode regression, and adds instance titles and a terminal bell.

It keeps the same Windows-hosted browser terminal model as `0.1.1`. The installer is the primary download from this release on; the portable zip stays available as a secondary download until the installer has proven itself across a release cycle.

## What changed

- Added a Windows installer: Program Files install, a password page, an optional before-sign-in auto-start checkbox, an install-time firewall rule for private networks, a Start Menu group, and an Apps & Features uninstall entry. Config and workspace state live under `%ProgramData%\TermiWeb`.
- Before-sign-in auto-start now registers a startup task that runs as `SYSTEM` with no stored credentials, so it never asks for a Windows account password and works on Hello-only and PIN-only sign-in setups. This applies to the zip too. Shells opened on an auto-started TermiWeb run as `SYSTEM` until it is stopped and started manually.
- Added `TERMIWEB_START_DIRECTORY` so new shells can open in a chosen folder; the installer fills it with the installing user's profile so auto-started shells open there instead of the `SYSTEM` profile.
- Fixed the mobile Select-mode regression where the selection panel closed on its own when the on-screen keyboard state changed.
- Instances now show the title the shell sets (OSC `0`/`2`), fall back to a stable `Instance N` number that never renumbers, and handle long titles with an ellipsis and tooltip on desktop and a back-and-forth scroll on phones.
- The terminal bell now works: the ringing instance's card flashes twice and keeps a bell badge until someone selects or types into it, the active terminal frame flashes, the browser tab shows a bell marker, and an off-by-default Sound toggle plays a tone (and vibrates on phones).
- Re-verified the `0.1.1` mobile fixes for collapsed instance controls and keyboard text assistance on real hardware.

## Install

1. Download `TermiWeb-0.1.2-windows-x64-setup.exe`.
2. Run it. The installer is unsigned, so SmartScreen shows "Windows protected your PC": choose `More info`, then `Run anyway`, and approve the Windows elevation prompt.
3. Choose the TermiWeb password and decide whether TermiWeb should start before sign-in.
4. Let the finish page start TermiWeb and open `http://127.0.0.1:22443`.

Portable zip: `TermiWeb-0.1.2-windows-x64.zip` keeps its config and state inside its own folder. Unpack it, open `1.Start-Here.md`, and run `Set Up TermiWeb.cmd`. Moving from the zip to the installer is described in the README.

## Operating boundaries

- Windows hosts only
- Every shell in `0.1` is elevated
- Built for a trusted private network
- WAN exposure is possible, but securing it is up to you
- Includes single-user auth without TLS to keep it simple
```

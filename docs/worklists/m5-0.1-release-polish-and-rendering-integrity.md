# M5 0.1 Release Polish And Rendering Integrity

Milestone Timing: Mirrors `M5` in [Project plan](../PLAN.md): start `2026-04-08`, end `2026-04-17` (extended by one week for continued dogfooding; `M6` intentionally ran in parallel during the final stretch, 2026-04-12 to 2026-04-13).

Status: Completed on 2026-04-17. Reconstructed retroactively on 2026-08-06 from git history and the changelog; the worklist convention was defined mid-milestone (2026-04-12, first applied to `M6`), so `M5` itself never had a contemporaneous worklist.

## Desired Outcome

TermiWeb should leave `M5` ready to be released as `0.1`: an explicit release standard, per-instance shared column width, terminal rendering that holds up under interactive CLIs, a shared terminal geometry model that phones cannot corrupt, the elevated-only run path proven live, and the remaining mobile issues logged as findings rather than silently shipped.
